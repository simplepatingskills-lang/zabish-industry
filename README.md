# Zabish Industry — two-category storefront starter

This responsive front-end demo focuses on exactly two main departments:

1. **Beauty Tools** — tweezers, hair scissors, nail clippers, cuticle nippers, eyebrow scissors and makeup brushes.
2. **Men’s Clothing** — leather jackets, hoodies, trousers, shirts, denim jackets and T-shirts.

## Open in Cursor / VS Code
1. Download and extract the ZIP.
2. Open Cursor.
3. Choose **File → Open Folder...** and select `zabish_industry_website`.
4. Open `index.html`.
5. Preview by double-clicking `index.html` in File Explorer, or use any available local preview/server extension.

No npm install or build command is required.

## Included demo features
- Responsive desktop/mobile layout and two main category panels.
- Search, currency display selector, wishlist, cart drawer and quantity controls.
- Sample products, prices, ratings and discount labels.

## Important before selling internationally
This is a front-end demo, not a production store. Product images are remote samples; replace them with your own product photos. Product details, prices, ratings and discounts are demo content. Cart contents are temporary and no orders or payments are processed.

Ordinary beauty tools such as tweezers and scissors are often simpler to list than cosmetics, liquids, medical devices or powered products, but **no product is guaranteed to require zero documents or checks in every country**. Check each destination’s import/customs rules, marketplace policies, product-safety and labelling requirements, and carrier restrictions before listing or exporting. Leather and textile garments can also have customs and textile-labelling requirements.

For a real store, connect a backend such as Supabase, admin product management, order storage, customer accounts, shipping/tax calculations and a payment provider that supports your business location.
